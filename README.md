# obsidian-ai-bridge

Telegram-бот, который превращает мысли, голосовые, фото, видео, статьи и PDF в заметки Obsidian
с помощью Gemini. Работает прямо с `.md`-файлами хранилища (Obsidian на сервере не нужен).

## Что умеет

**Сохранение в Inbox**
- Текст, голос, фото, видео, аудио, PDF, `.txt`/`.md` → структурированная заметка.
- Ссылка на YouTube / Instagram / VK / RuTube / TikTok → конспект видео (субтитры или аудио через yt-dlp).
- Ссылка на статью → конспект статьи.
- Если ИИ недоступен, текст всё равно сохраняется как есть (тег `raw`).
- Связи `[[...]]` ставятся только на реально существующие заметки.
- Кнопки под заметкой: в «Учеба», в «Проекты», ссылка в дневник, удалить (уходит в `.trash`).

**Команды**

| Команда | Что делает |
|---|---|
| `/idea текст` | разбор идеи: риски, проверка за 1–2 дня, шаги |
| `/task текст` | задача с шагами `- [ ]` |
| `/learn тема` | объяснение простыми словами + карточки |
| `/d текст` | быстрая запись в дневник `Daily/ГГГГ-ММ-ДД.md` |
| `/ask вопрос` | ответ по вашим заметкам со ссылками на них |
| `/tasks` | все незакрытые задачи из хранилища |
| `/inbox` | что ждёт разбора |
| `/quiz [тема]` | вопросы по вашим конспектам, проверка ответов (`/skip`, `/stop`) |
| `/cards` | повторение карточек (интервалы 1, 2, 4, 8, 16, 32 дня) |
| `/study тема часы` | журнал учёбы, например `/study Angular 1.5` |
| `/review` | обзор недели, сохраняется в папку `Обзоры` |

Ежедневно в заданный час бот присылает напоминание: карточки, старые заметки в Inbox, открытые задачи.

## Установка

Нужны Node.js 20+ и (для видео) `yt-dlp` с `ffmpeg`.

```bash
npm install
cp .env.example .env   # заполните значения
npm start
```

Тесты (Telegram и Gemini в них имитируются): `npm test`.

## Как заметки попадают на телефон и компьютер

Бот пишет файлы в папку на сервере. Чтобы они появились в Obsidian на ваших устройствах,
синхронизируйте эту папку: например Syncthing (бесплатно) или git. Ссылки `obsidian://`
в сообщениях бота откроются только на устройстве, где хранилище уже синхронизировано.

## Запуск на сервере

Через pm2:

```bash
npm install -g pm2
pm2 start src/index.js --name obsidian-bot
pm2 save && pm2 startup
```

Обновление yt-dlp, если YouTube перестал отдавать видео: `pip install -U yt-dlp`.

## Безопасность

- Бот отвечает только пользователю с `ALLOWED_USER_ID`, остальных игнорирует.
- Ссылки передаются в yt-dlp как аргументы без shell; адреса localhost и внутренних сетей отклоняются.
- Данные бота (`data/`) и `.env` не попадают в git.
